# Seminario de Investigación III

Sitio web del curso **Seminario de Investigación III** — Maestría en Salud Pública, Fundación Universitaria del Área Andina.

Metodología del curso (núcleo común, rutas diferenciadas cuantitativa/cualitativa), rúbricas SOLO, ruta de sesiones y caja de herramientas interactiva de validación metodológica.

🔗 **Sitio publicado:** https://doccpaez4-commits.github.io/SeminarioIII/

## Estructura

- `index.md` — presentación del curso
- `metodologia.md` — metodología didáctica
- `contenidos.md` — ruta de sesiones
- `proyecto.md` — entregas del proyecto de grado
- `evaluacion.md` — criterios de evaluación
- `rubricas.md` — rúbricas SOLO
- `bibliografia.md` — bibliografía del curso
- `herramientas/caja-herramientas.html` — caja de herramientas interactiva (COSMIN, CVI/CVR, COREQ, CASP, MMAT)

## Publicación

Este sitio se construye automáticamente con Jekyll vía GitHub Pages a partir de la rama `main`.
